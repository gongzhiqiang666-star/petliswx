# 宠物检测预约和管理系统

一个完整的宠物健康管理应用，专为移动端设计，包含预约检测、订单管理、PDF报告查看和宠物档案管理等功能。

## 🎨 设计规范

- **画板尺寸**: 375x812 px (移动端优先)
- **字体**: PingFang SC 系统字体
- **主色调**: #6366F1 → #8B5CF6 紫色渐变
- **辅助色**: 
  - 成功: #10B981 (绿色)
  - 警告: #F59E0B (橙色)
  - 错误: #EF4444 (红色)
- **圆角**: 12px (卡片), 8px (输入框), 24px (按钮)
- **阴影**: 0 4px 24px rgba(0, 0, 0, 0.08)

## 📱 功能模块

### 1. 首页 (Home)
- 快速统计概览（待完成预约、检测报告、健康趋势）
- 快捷服务入口（预约检测、查看报告）
- 最近动态列表

### 2. 宠物管理 (Pets)

#### 2.1 宠物列表页
- 显示所有宠物卡片（头像、名字、品种、年龄、性别、体重）
- 搜索功能（支持中英文名）
- 快速编辑和删除
- 宠物对比入口
- 悬浮添加按钮 (FAB)

#### 2.2 添加/编辑宠物

**基本信息**:
- 宠物照片上传
- 宠物中文名（必填）- `AnimalName`
- 宠物英文名（必填）- `AnimalName_en`
- 物种选择（必填，默认乌龟）- `InfoAnimalId`
- 品种ID - `AnimalTypeId`
- 性别：未知/公/母/其他（必填）- `DictSexId`

**体征信息**:
- 出生日期（必填，狂犬检测必填）- `Birthday`
- 年龄（自动计算或手动填写）- `Age`
- 体重 (kg) - `AnimalWeight`
- 芯片号（狂犬检测必填）- `ChipNO`

**数据库字段映射**:
- `InfoAnimalId`: 物种ID (1-猫/2-狗/3-兔/4-乌龟/5-其他，默认4)
- `AnimalTypeId`: 品种ID (关联lb_infovariety表)
- `DictSexId`: 性别ID (0-未知/1-公/2-母/3-其他)
- `Birthday`: 出生日期 (狂犬检测必填)
- `ChipNO`: 芯片号 (狂犬检测必填)

#### 2.3 宠物详情页
- 渐变背景头部展示（中英文名）
- 快速统计栏（物种、年龄、性别、体重）
- 基本信息卡片（完整字段显示）
- 检测报告列表（可直接跳转查看PDF报告）
- 底部操作按钮（编辑信息、预约检测）

#### 2.4 健康记录页
保留原有功能（疫苗、体检、医疗记录）

#### 2.5 宠物对比页
- 最多对比3只宠物
- 对比维度：基本信息、健康状态、检测记录
- 添加自定义对比项

### 3. 订单管理 (Orders)

#### 3.1 订单列表页
- 四个标签筛选：全部、待支付、进行中、已完成
- 订单卡片显示：宠物信息、预约时间、检测项目、价格、状态
- 快速操作：查看详情、立即支付、取消订单

#### 3.2 订单详情页
- 渐变背景状态展示
- 订单号显示
- 宠物信息卡片（6项基本信息）
- 预约信息卡片（日期、时间、地址、电话、备注）
- 检测项目卡片（项目列表、价格汇总）
- 支付信息卡片（支付方式、状态、时间、交易号）
- 底部操作：联系客服、再次预约

#### 3.3 预约流程

**第1步 - 选择宠物和时间**:
- 宠物选择卡片（支持添加新宠物）
- 日期选择器（日历视图）
- 时间段选择（9:00-16:00，按小时）
- 步骤指示器（1-2-3）

**第2步 - 选择检测项目**:
- 搜索框
- 分类标签（全部、基础检查、生化检查、基因检测、其他）
- 项目卡片：名称、价格、分类、预计时长、描述、推荐星级
- 多选功能
- 底部固定栏（已选数量、总价、下一步）

### 4. 报告管理 (Reports)

#### 4.1 报告列表页
- 搜索和筛选功能
- 分类标签（全部报告、待出、已完成）
- 报告卡片：报告类型、宠物信息、检测日期、结果状态
- 查看完整报告按钮

#### 4.2 报告查看页（PDF模式）
- 渐变背景头部（报告类型、宠物信息、检测日期）
- 报告信息卡片：
  - 报告编号
  - 宠物名称
  - 检测日期
  - 报告日期
  - 检测结果
- PDF报告卡片：
  - PDF文件图标
  - 文件名显示
  - 点击查看PDF（新窗口打开）
- 使用说明
- 底部操作：
  - 下载报告（Download）
  - 查看PDF（在新窗口打开）

## 🎯 交互特性

1. **流畅的页面导航**
   - 底部导航栏（首页、宠物、订单、报告）
   - 返回按钮
   - 宠物详情→报告查看直达

2. **智能表单验证**
   - 必填项提示（红色星号）
   - 实时年龄计算（根据出生日期）
   - 字符计数
   - 物种选择自动填充英文名

3. **视觉反馈**
   - 按钮悬停效果
   - 卡片阴影
   - 加载状态
   - 空状态插图

4. **搜索和筛选**
   - 实时搜索（支持中英文）
   - 清除按钮
   - 标签筛选
   - 状态过滤
