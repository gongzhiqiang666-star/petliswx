## 🔍 性能监控方法

### 方法1: 使用微信开发者工具Performance面板

1. 点击调试器的"Performance"标签
2. 点击"Record"按钮
3. 执行一些操作（点击检测项目、切换页面等）
4. 点击"Stop"按钮
5. 查看性能图表

**正常情况**:
- 大部分操作应该在16ms内完成（60fps）
- 没有长任务（超过50ms的任务）

**异常情况**:
- 如果看到红色长任务条，说明有性能问题

### 方法2: 使用setUpdatePerformanceListener（开发者用）

在需要测试的页面添加：

```javascript
Page({
  onLoad() {
    // 监控setData性能
    this.setUpdatePerformanceListener({ withDataPaths: true }, (res) => {
      const duration = res.updateEndTimestamp - res.updateStartTimestamp;
      console.log('setData耗时:', duration, 'ms');
      
      if (duration > 16) {
        console.warn('⚠️ 性能警告: setData耗时过长', res);
      }
    });
  }
});
```

### 方法3: Console日志观察

正常的日志应该类似：

```javascript
[OrderTestItems] 切换分类: 1
[Request] GET http://localhost:8081/api/dictionary/test-types
[Response] [...]
```

如果有性能问题，会看到：
- 大量重复的日志
- API请求堆积
- setData调用频繁

## 🚨 如果还有卡顿

### 临时解决方案

1. **关闭实时日志** (Console标签)
   - 实时日志会影响性能
   - 开发时可以关闭

2. **关闭真机调试**
   - 真机调试模式会增加开销
   - 使用模拟器测试即可

3. **减少数据量**
   - 如果检测项目有几百个
   - 可以先加载前50个测试

### 根本解决方案

如果问题持续，请提供以下信息：

1. **Console日志截图**
   - 红色错误信息
   - API请求日志
   - setData调用频率

2. **Performance面板截图**
   - 录制一段操作
   - 查看是否有长任务

3. **具体操作步骤**
   - 哪个页面卡顿
   - 执行了什么操作
   - 卡顿多久
