## 二、数据字典相关接口

### 2.1 获取物种列表

**接口**: `GET /dictionary/animals`

**前端调用**: `api.dictionary.getAnimals()`

**后端响应**: `List<AnimalResponse>`

**字段映射**:

| 后端字段 (AnimalResponse) | 前端使用 | 类型 | 说明 |
|-------------------------|---------|------|------|
| infoAnimalId | id | Integer | 物种ID |
| animalName | name | String | 物种中文名 |
| animalNameEn | name_en | String | 物种英文名 |
| isActive | - | Integer | 启用状态 |
| createtime | - | Integer | 创建时间 |
| updatetime | - | Integer | 更新时间 |

**前端数据转换**:
```javascript
const animalSpecies = animals.map(item => ({
  id: item.infoAnimalId,
  name: item.animalName,
  name_en: item.animalNameEn
}));
```

### 2.2 获取品种列表

**接口**: `GET /dictionary/varieties?animalId={id}`

**前端调用**: `api.dictionary.getVarieties(animalId)`

**后端响应**: `List<VarietyResponse>`

**字段映射**:

| 后端字段 (VarietyResponse) | 前端使用 | 类型 | 说明 |
|--------------------------|---------|------|------|
| iid | iid | Long | 品种ID |
| varietyCn | varietyCn | String | 品种中文名 |
| varietyEn | varietyEn | String | 品种英文名 |
| createtime | - | Integer | 创建时间 |
| updatetime | - | Integer | 更新时间 |

**修复前后对比**:
```javascript
// 修复前 (错误的字段名)
const mockBreeds = [
  { IID: 1, Variety_CN: '泰迪', Variety_EN: 'Teddy' }
];

// 修复后 (正确的字段名，且使用真实API)
const breeds = await api.dictionary.getVarieties(animalId);
// breeds = [{ iid: 1, varietyCn: '泰迪', varietyEn: 'Teddy' }]
```

## 四、API 调用流程

### 4.1 宠物建档完整流程

```
1. 用户打开 pet-add 页面
   ↓
2. onLoad() 触发
   ↓
3. loadDictionaryData() 并行加载：
   - api.dictionary.getAnimals() → 获取物种列表
   - api.dictionary.getSexes() → 获取性别列表
   ↓
4. 用户选择物种
   ↓
5. onSpeciesChange() 更新 formData.infoAnimalId
   ↓
6. 用户点击"选择品种"
   ↓
7. 跳转到 breed-select 页面，传递 animalId
   ↓
8. breed-select.onLoad() 触发
   ↓
9. loadBreeds() 调用：
   - api.dictionary.getVarieties(animalId) → 获取品种列表
   ↓
10. 用户选择品种
    ↓
11. onSelectBreed() 将品种信息传回 pet-add 页面
    ↓
12. 用户填写其他信息
    ↓
13. 点击"保存"
    ↓
14. validateForm() 验证表单
    ↓
15. api.pets.create(formData) → 创建宠物档案
    ↓
16. 成功后返回上一页
```

## 七、注意事项

1. **字段命名规范**: 前后端统一使用 camelCase 命名
2. **必填字段**:
   - 宠物中文名 (animalName)
   - 物种ID (infoAnimalId)
   - 性别ID (dictSexId)
   - 畜主中文名 (ownerName)
3. **狂犬检测必填**: chipNo 和 birthday（如果是狂犬检测订单）
4. **品种选择**: 品种ID (infoVarietyId) 是可选的，但建议填写
5. **日期格式**: birthday 使用 yyyy-MM-dd 格式
