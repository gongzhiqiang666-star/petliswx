# 微信用户认证与医院关联 - User Story 1

## 概述

本模块实现了微信小程序用户认证功能,包括微信登录、JWT token生成、用户自动注册、医院关联等功能。

## 功能特性

### 1. 微信登录 (POST /api/auth/wechat/login)

- 通过微信code换取openid
- 自动创建或更新用户信息
- 关联默认医院(hospitalId=1)
- 生成JWT token返回

**请求示例:**
```json
{
  "code": "071abc2w3defG4H5I6J7"
}
```

**响应示例:**
```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "token": "<JWT_TOKEN>",
    "userId": 1,
    "hospitalId": 1,
    "hospitalName": "Laboklin实验室",
    "openid": "oXYZ123..."
  }
}
```

### 2. Token刷新 (POST /api/auth/refresh)

- 使用当前token刷新获取新token
- 延长用户登录状态

**请求头:**
```
Authorization: Bearer {token}
```

### 3. 登出 (POST /api/auth/logout)

- 用户登出系统
- 可选: 将token加入黑名单(Redis实现)

### 核心组件说明

#### 1. AuthService (认证服务)

**职责:**
- 微信登录业务逻辑
- Token刷新
- 用户登出

**关键方法:**
- `wechatLogin()`: 处理微信登录流程
- `refreshToken()`: 刷新JWT token
- `logout()`: 用户登出

#### 2. JwtAuthenticationFilter (JWT认证过滤器)

**职责:**
- 从请求头中提取JWT token
- 验证token有效性
- 解析用户信息(userId, openid, hospitalId)
- 设置到SecurityContext

**特点:**
- 自动拦截所有请求(除了白名单路径)
- 将用户信息封装为UserPrincipal
- 记录详细的认证日志

#### 3. SecurityUtils (安全工具类)

**职责:**
- 从SecurityContext获取当前用户信息
- 提供便捷的用户身份验证方法

**主要方法:**
```java
// 获取当前用户主体
UserPrincipal user = SecurityUtils.getCurrentUser();

// 获取用户ID
Integer userId = SecurityUtils.getCurrentUserId();

// 获取医院ID
Integer hospitalId = SecurityUtils.getCurrentHospitalId();

// 检查是否已登录
boolean authenticated = SecurityUtils.isAuthenticated();
```

#### 4. DataPermissionAspect (数据权限切面)

**职责:**
- 拦截Service层方法
- 自动记录医院ID
- 确保用户只能访问本院数据

**使用方式:**
- 自动应用,无需手动配置
- 在日志中可以看到用户ID和医院ID

#### 5. OperationLogAspect (操作日志切面)

**职责:**
- 拦截带有@OperationLog注解的方法
- 记录操作日志(模块、操作、描述、用户、医院、耗时)

**使用示例:**
```java
@PostMapping("/wechat/login")
@OperationLog(module = "认证管理", operation = "微信登录", description = "用户使用微信code登录系统")
public Result<WechatLoginResponse> wechatLogin(@Valid @RequestBody WechatLoginRequest request) {
    // ...
}
```

## 数据权限隔离

### 实现方式

1. **Repository层过滤**
   - 在自定义查询中添加`hospitalId`条件
   - 使用`@Query`注解确保数据隔离

2. **Service层验证**
   - 使用`SecurityUtils.getCurrentHospitalId()`获取当前医院ID
   - 在业务逻辑中验证数据权限

3. **AOP切面记录**
   - `DataPermissionAspect`自动记录所有Service调用
   - `OperationLogAspect`记录关键操作

### 示例代码

**Repository查询示例:**
```java
@Query("SELECT u FROM User u WHERE u.hospitalId = :hospitalId AND u.status = 'normal'")
List<User> findByHospitalId(@Param("hospitalId") Integer hospitalId);
```

**Service层使用示例:**
```java
@Service
@RequiredArgsConstructor
public class UserServiceImpl implements UserService {

    private final UserRepository userRepository;

    public List<User> getCurrentHospitalUsers() {
        // 获取当前医院ID
        Integer hospitalId = SecurityUtils.getCurrentHospitalId();

        // 只查询本院用户
        return userRepository.findByHospitalId(hospitalId);
    }
}
```

## 安全注意事项

1. **JWT Secret**: 生产环境必须更改默认的JWT密钥
2. **微信AppID/Secret**: 妥善保管,不要泄露到版本控制
3. **HTTPS**: 生产环境必须使用HTTPS
4. **Token过期**: 合理设置token过期时间(默认7天)
5. **数据隔离**: 确保所有查询都带上hospitalId过滤

## 问题排查

### 常见问题

1. **微信登录失败**
   - 检查appid和secret配置是否正确
   - 确认code是否有效(5分钟内使用)
   - 查看微信接口返回的错误码

2. **Token验证失败**
   - 检查token格式: `Authorization: Bearer {token}`
   - 确认token未过期
   - 检查JWT secret配置

3. **数据权限问题**
   - 确认用户已关联医院ID
   - 检查Repository查询是否包含hospitalId过滤
   - 查看日志中的医院ID是否正确
