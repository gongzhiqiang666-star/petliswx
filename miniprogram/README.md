# 宠物LIS 微信小程序

这是从React代码转换而来的宠物LIS（Laboratory Information System）微信小程序版本。

## 项目结构

```
miniprogram/
├── app.js                 # 小程序逻辑
├── app.json              # 小程序配置
├── app.wxss              # 全局样式
├── project.config.json   # 项目配置
├── sitemap.json          # 站点地图
├── pages/                # 页面目录
│   ├── home/             # 首页
│   ├── pets/             # 宠物列表
│   ├── orders/           # 订单列表
│   ├── mine/             # 我的页面
│   ├── order-select-pet/ # 预约检测-选择宠物
│   ├── pet-add/          # 宠物建档
│   └── report-list/      # 报告列表
└── images/               # 图片资源（需要添加）
```

## 已实现的功能

### 1. 首页 (home)
- 顶部渐变背景区域
- 欢迎信息和用户头像
- 快捷操作按钮（预约检测、宠物建档、查看报告）
- 最近动态列表
- 底部导航栏

### 2. 宠物列表 (pets)
- 宠物列表展示
- 搜索功能
- 添加宠物按钮
- 编辑宠物功能入口
- 空状态提示

### 3. 订单列表 (orders)
- Tab切换（全部、待支付、进行中、已完成）
- 订单卡片展示
- 订单状态标识
- 查看订单详情入口

### 4. 我的页面 (mine)
- 用户信息卡片
- 医院信息展示
- 功能菜单列表
- 退出登录功能

### 5. 预约检测 (order-select-pet)
- 选择宠物
- 快速预约选项
- 自定义项目选项
- 添加新宠物入口

### 6. 宠物建档 (pet-add)
- 基本信息表单（中文名、英文名、物种、品种、性别）
- 体征信息表单（出生日期、年龄、体重、芯片号）
- 主人信息表单（中文名、英文名）
- 表单验证
- 自动计算年龄功能

### 7. 报告列表 (report-list)
- 搜索和筛选功能
- 分类标签（全部报告、待出、已完成）
- 报告卡片展示
- 状态标识（正常、需注意、检测中）
- 查看报告详情入口

## 如何使用

### 1. 准备开发环境

- 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
- 注册微信小程序账号

### 2. 导入项目

1. 打开微信开发者工具
2. 选择"导入项目"
3. 选择 `miniprogram` 目录
4. 填写项目信息（AppID可先使用测试号）

### 3. 添加图片资源

参考 `images/README.md` 文件，在 `miniprogram/images/` 目录下添加所需的图片资源。

**临时方案**：在开发阶段，可以先注释掉图片相关的代码，或者使用纯色块代替。

### 4. 运行项目

点击微信开发者工具的"编译"按钮，即可在模拟器中查看效果。

## 注意事项

### 图片资源

当前代码中引用了多个图片资源，但实际图片文件需要您自己添加。您可以：

1. 使用现有的设计稿导出图片
2. 从图标库下载合适的图标
3. 使用纯CSS绘制简单图标

### API对接

当前使用的是模拟数据，实际使用时需要：

1. 替换 `app.js` 中的 `loadMockData()` 为实际API调用
2. 配置服务器域名
3. 实现用户登录、数据存储等功能

### 页面跳转

部分功能按钮绑定了 `wx.showToast` 作为占位，实际使用时需要实现相应的页面跳转或功能逻辑。

## 技术栈

- 微信小程序原生开发

- WXSS（样式）
- JavaScript（逻辑）

## 从React转换的说明

本小程序是从React代码转换而来，主要转换内容包括：

1. **JSX → WXML**：模板语法转换
2. **CSS → WXSS**：样式单位转换（px → rpx）
3. **React组件 → 小程序页面**：组件结构调整为小程序页面结构
4. **React Hooks → 小程序Page**：状态管理和生命周期调整
5. **lucide-react图标 → 图片资源**：图标组件转换为图片引用
