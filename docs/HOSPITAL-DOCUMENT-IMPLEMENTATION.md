# 医院资料文件补齐

已核实医院档案只有查看入口，通用QUALIFICATION上传不能替代明确医院归属的资料管理。本次复用lin_file与lin_audit_record，不新增或调整结构。

第一版由PC平台管理员维护：指定医院上传PDF/PNG/JPEG、资料类型（执照/合作/其他）和原因；医院ID在服务端校验，不取客户端任意归属。文件为PRIVATE，通用上传不能伪造本业务类型，普通医生/跨机构/匿名不得下载。原医生资质重审与此独立。

上传用稳定请求号和内容指纹防重复；可选择替换前一文件，保留前后独立文件ID、原文件及审计。锁医院后防止同一前序产生两条替换分支。分页列表展示历史及替换关系；不提供物理删除。失败保留表单，替换过期明确冲突，旧文件仍仅管理员可查。

验证已覆盖文件类型/内容、医院归属、同请求重放/换内容、跨角色下载、替换/旧历史、实库并发与失败及真实PC操作，当前证据见[医院资料验证](HOSPITAL-DOCUMENT-VALIDATION.md)。不以此代替医院资料审批或医生资质审核。医院管理员自助入口及原PHP资料管理完整对等属于后续范围，不能据此宣称全部医院资料功能完成。
