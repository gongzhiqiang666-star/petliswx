# 资质上传归属与兼容

复用lin_audit_record，不做DDL。上传记录使用QUALIFICATION资源及文件UUID名；登录上传记录本人，匿名上传返回32字节随机一次性凭据，仅保存SHA256和2小时有效期。注册需同时提交每个匿名文件的凭据，短信验证及用户创建后，在同一事务锁上传记录并追加领取审计；抢先/重复领取或跨账号复用拒绝，注册回滚不消耗凭据。

资料重审仅允许本人上传/已领取文件；无上传记录的历史文件，只允许当前已审核医生档案原本包含的引用继续使用，不允许新注册账号凭地址领取旧文件。资质读取允许本人及审核人员；同院其他医生和匿名仍不可读。预览走鉴权下载，不公开文件地址。

前端注册仅在内存保存上传凭据并随申请提交，成功后清空；资料页提供文件预览。凭据不写日志、仓库、URL查询串或持久化草稿。旧客户端对新增匿名注册文件需升级/重新上传；既有登录账号与已审核资质不强制换文件。

验证需覆盖匿名凭据缺失/错误/过期/重复领取、并发单次领取、注册事务回滚、本人/他人/审核员读取、历史兼容、新旧审核流程、原生上传预览与注册提交。任何只通过文件存在检查的旧实现不算归属完成。
