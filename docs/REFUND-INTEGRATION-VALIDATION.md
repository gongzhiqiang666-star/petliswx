# 异常订单退款联调

## 已修复的问题

1. 修复前，本机现结测试23928四并发退款返回200/404/404/404。普通审计读取先建立RR快照，随后其他事务改变付款状态，后续请求的已付款关联查询找不到记录，未能幂等返回。现在先锁定原订单，再做审计当前读，退款事务使用READ_COMMITTED；同一订单只执行一次全额退款，其他请求返回既有结果。
2. 原详情/列表没有退款标识，医生只能看到送检进度。现增加独立财务状态refunded，详情含refundAmount/refundReason/refundedAt/refundMock；列表批量读取本页ID的已完成退款审计，避免逐单查询。原SampleStatus与医疗/物流记录保留。
3. 兼容实际JDBC将DATETIME返回LocalDateTime的情况；管理列表查询显式兼容审计表utf8mb4_unicode_ci与连接排序规则，不调整表字符集/索引/数据库全局设置。
