# 月结逾期与催款提醒验证

## 修复的问题

真实HTTP复现：尚未双边对账的账单发送逾期提醒后变为OVERDUE，原对账入口只允许PENDING_RECONCILIATION/DISPUTED，导致后续无法对账和结清。合成本机账单3返回409；私有证据 `qa/overdue-reconciliation-before.json`。

修正：未完成双边对账的OVERDUE允许继续确认或异议；逾期日期仍保留OVERDUE状态，双方齐全时记录reconciled_at，随后既有结算入口可结清。已经完成双方确认的OVERDUE、RECONCILED及SETTLED仍不允许通过普通对账入口倒退。

已结清账单的overdueDays按结清日计算，避免结清后每日继续增加；历史SETTLED且缺失结清时间的记录不伪造结清日期。仅修改应用查询/状态判断，无结构或全局数据库配置变化。

## 管理端入口

财务账单列表增加最近提醒时间；仅授权ADMIN/LAB_STAFF在已逾期、未结欠款大于0、尚未提醒且未结清时看到“逾期提醒”。点击需确认，提交期间禁用按钮。服务端再次校验范围、日期和金额，锁账单防并发；通知稳定业务键 `bill:{id}:overdue`，每账单一次，并保存操作审计。

通知先写站内消息与既有推送队列，不把“已记录”当作真实微信或短信送达；本机调度继续关闭，无自动催款。
