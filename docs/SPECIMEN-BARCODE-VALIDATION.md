# 标本标签真实解码与接续验证

## 发现与修复

2026-11-08检查F40打印实现，发现原Code39起止符模式错误，连字符与B使用相同模式；固定420宽SVG还可能截断长编号。原实现将小写自动转大写，会改变扫描所得的原编号；输入星号可被当作内部终止符。

编码事实核对来源：[ZXing Code39Reader](https://github.com/zxing/zxing/blob/master/core/src/main/java/com/google/zxing/oned/Code39Reader.java)。重核标准43字符和起止符，按实际条纹宽度生成SVG画布、左右至少10个窄模块静区；保持原编号，不悄悄大写，无法按标准编码、内部星号、空/超长编号明确拒绝。先成功生成图再记录打印审计，失败不留下成功打印记录。送检单标题中的原编号也按文本转义。

没有改动或重编历史业务编号/订单/档案，没有改数据库结构。Code39不支持的小写等原编号目前明确拒绝打印，不能把拒绝当作已支持全部历史格式；后续确有此类真实编号需保留原值另行选择可精确承载的码制。未擅自统一为新编号。
