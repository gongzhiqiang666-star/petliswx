# 医院资料自助提交与审核

当前已批准计划中医院资料上传/审核的缺口，继续开发，不扩大为重新设计医院入驻账号体系。既有ADMIN上传直接归档行为保留；HOSPITAL_ADMIN可向自己有权限的医院提交执照/合作/其他资料，待审核不会替换旧版本。普通医生、跨院管理员、配送/实验人员均不可管理或下载医院私有资料。

复用lin_file与lin_audit_record，无DDL。待审资料biz_type为HOSPITAL_DOCUMENT_REVIEW；提交/审批/驳回持久化审计，批准后改为现有HOSPITAL_DOCUMENT并追加现有归档审计，纳入版本历史。驳回保留文件与原因，不删除原件。医院启停沿用独立入口，不因一份文件通过擅自启用医院。

提交幂等绑定操作人、文件摘要、医院、类型、替换前序与原因；并发提交同一请求只一文件。替换仅针对本院同类型未被替换的已生效文件；同前序只一待审申请。批准前重新核验前序，防止待审期间旧版被ADMIN替换后覆盖错误版本；冲突保留待审供人工核对，不自动改父链。审核结果在同一事务生成提交人站内消息，重放不重复；不启用消息发送作业。审核原因必填，同请求重放不重复审计，不同结论/已处理申请拒绝。

前端新增医院资料工作台（仅医院管理员/平台管理员），展示待审/通过/驳回、历史版本和原因，鉴权下载；审核中心增加医院资料待审列表并允许核对附件。失败保留输入与请求号；切换医院不得串资料。

验证：正常提交批准/驳回重提、旧版审批前仍有效、幂等及冲突、同前序并发、跨院/医生拒绝、文件字节与历史、待审期间旧版变更、前端路由及权限/失败重试、真实HTTP与浏览器。无外发、无调度、无生产/原库写入。
