## 基准与范围

- 功能基准：`宠物医院实验室小程序功能规划.xlsx` 的「现有功能模块」。不纳入物流、条码、临床资料回写、独立月账单、钱包抵扣等超出范围的设计。
- 视觉基准：`/Users/apple/claudelife/petlis/petlis_v2.pen`（当前画布）。使用原生导航与胶囊，不重复绘制手机状态栏。
- 首批页面：首页、送检流程（填写资料 / 选择项目 / 确认送检）、报告详情、「我的」，以及共享视觉组件。
- 数据原则：所有数字和状态来自真实接口；没有数据源的指标（异常提醒、本月消费、待开票聚合等）不展示、不虚构。

## 页面设计

### 首页

- 状态卡：真实医院、医生姓名、资质审核状态。
- 入口格：我要检测 / 档案中心 / 钱包 / 优惠券 / 送检记录 / 发票 / 报告中心 / 消息中心。设计稿的「账单」无独立功能，以送检记录替代。
- 今日待办：真实订单状态计数（待支付、待审核、待报告），来自现有 `/orders` 分页 totalElements。
- 最近业务进度：真实最近订单及状态。
- 财务摘要：真实个人余额（`/account`）与充值入口；无聚合接口的指标不显示。
- 最新提醒：真实消息中心最近两条。

### 送检流程

- 保持真实三步：填写资料 → 选择项目 → 确认送检；步骤条、已选档案卡、实验室与项目卡、费用确认卡采用设计稿视觉，不虚构「临床」步骤。
- 保留草稿、服务端核价、驳回重提与前置必填校验（宠物中/英文姓名、品种、样本类型等）。

### 报告详情

- 宠物与状态头部、基础送检信息、未支付锁定预览（沿用已实现的服务端限制）、PDF 预览与下载区，按设计稿重排。

### 我的

- 资料卡 + 设计稿同款菜单列表，保留全部真实入口（宠物档案、送检记录、账户、商城、优惠券、发票、资讯、通知偏好、个人资料等）。

## 视觉系统

- 浅青灰页面底、白色卡片、柔和圆角、浅绿入口格、深青财务/状态卡。
- 状态色：待支付橙、正常绿、异常红；状态同时配图标与文字，不单靠颜色。
- 统一字号层级：正文 ≥28rpx，标题与辅助文字按统一梯度。

## 图标与图片规范

- 按钮、菜单、状态使用正式图标资源，禁止 emoji、Unicode 符号、文字箭头充当图标（替换现有 📋、› 等）。
- 统一线性图标风格，与画布一致；PNG/WebP 多倍图（24px 基准提供 @2x/@3x），统一 `assets/icons/` 目录与命名、统一显示尺寸。
- 图片使用 `image` 组件并指定 `mode` 与固定容器，避免拉伸变形；资源本地化并控制主包体积。

## 手机端体验

- 可点区域 ≥44px（88rpx）；主要操作固定底部拇指区并预留 `safe-area-inset-bottom`。
- 长文本换行或省略，不撑破卡片；表单键盘不遮挡输入与底部按钮。
- 列表使用页面原生滚动，避免嵌套滚动容器；高频主路径（送检 → 支付 → 看报告）单手可完成。
