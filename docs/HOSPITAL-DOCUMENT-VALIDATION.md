# 管理员医院资料上传与历史验证

## 实现范围（2026-11-08）

依据补充报价表的医院资料上传缺口，新增医院档案“资料文件”入口与`/admin/hospitals/{id}/documents`列表/上传接口，复用lin_file、lin_audit_record，无DDL、没有更改原PHP结构。范围为平台ADMIN维护，普通医生、医院管理员及匿名不获该权限；医院管理员自助和资料审批不是本轮交付。

支持执照/合作/其他类型，PDF/PNG/JPEG最大10MB，必须写原因。指定医院必须存在，替换前文件必须属于同医院、同资料类型且未被替换。稳定请求号校验内容、文件名、MIME和文件指纹；锁操作人及医院后去重/检查前序，过期替换不能形成分叉。旧文件不删除，列表分页、加载历史，旧版本仍仅ADMIN可下载。

补齐文件保存失败处理：元数据插入失败或后续事务回滚时仅清理本次新建文件；不会删除其他文件。清理I/O失败记录警告，不承诺在磁盘故障下必然成功。中文下载名使用RFC5987编码，既有PC下载工具识别UTF-8文件名。
