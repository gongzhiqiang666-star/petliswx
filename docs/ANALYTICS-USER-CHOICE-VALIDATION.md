# 使用统计本机开关验证

日期：2026-11-08，属于F13关闭行为和已批准小程序流程优化，不涉及数据库结构。

## 用户操作

“我的→通知与隐私”增加使用情况统计开关，和业务通知偏好分开：本机统计即时保存，通知仍由底部“保存通知设置”提交服务端。文案说明统计仅含步骤/结果，不包含姓名、手机号或诊疗内容；关闭不影响送检/通知，已送达统计不会自动删除。本机偏好切换账号仍生效，不声称跨设备同步或替代微信平台隐私授权。

沿用原默认开启策略。部署analyticsEnabled=false仍是上限，用户不能覆盖。wx扩展配置或偏好读取异常时停止统计，避免错误情况下忽略用户选择。未提供对任意字段、原始异常或诊疗内容的上传能力。

## 行为与失败处理

analytics.setEnabled持久化独立键petlis_analytics_enabled_v1；关闭清除待发队列并尽力abort当前统计请求。无法保证撤回网络侧已经接收的请求，所以不承诺删除历史记录。采集/flush均检查开关。

偏好写入失败显式反馈；队列清理失败仍保持已存的关闭状态，并反馈重试，重新开启前必须成功清队列，不能把关闭前残留事件重放。界面错误独立于通知错误，不清除通知表单或将本机设置塞入业务通知接口。

新增四项analytics行为测试先红后绿：关闭/重开不重放、中止在途且不能覆盖部署关闭、偏好写失败、队列清理失败后阻止复开。另两项页面测试验证即时本机保存与通知隔离、失败可直接重试。小程序完整98项通过，69JS/53JSON检查通过，日志/tmp/petlis-analytics-choice-tests.log和petlis-analytics-choice-static.log。
