# 资质归属与注册失败恢复验证（2026-11-08）

## 已实现

登录上传归属当前账号；注册上传始终匿名，即使前端有旧会话也不附带认证。匿名文件返回随机一次性凭据（2小时），服务端仅持久化SHA256摘要，注册与领取在同一READ_COMMITTED事务中完成。领取锁定上传审计行；同一凭据只能绑定一个新账号。资料重审必须使用本人文件，读取限本人或审核人员。

归属与领取记录复用 `lin_audit_record`；不新增表、不改字段/索引/触发器。归属记录是业务凭证，后续日志保留策略不得把它当临时诊断日志清理。已审核档案中无归属登记的旧引用允许原本人继续使用；新注册不能凭旧URL冒领。旧注册客户端需更新上传凭据协议，不能静默兼容不安全的URL复用。

资料页新增鉴权下载后的预览；PDF走openDocument，图片走previewImage。注册页内存保存凭据，成功清空，不写持久化草稿或日志；选择器打开期间阻止重复上传。

联调暴露短信正确验证码在独立事务先被删除的问题：现拆分为独立事务记录错误尝试，成功消费加入业务事务，注册等后续失败时验证码回滚保留。消费前再次锁定核对同一条最新验证码，避免并发重复使用。未启用真实短信服务。
