# 微信支付配置说明

## 概述

本文档详细说明如何配置PETLIS系统的微信支付功能。

## 前置条件

1. 已注册微信支付商户账号
2. 已开通小程序支付功能
3. 已获取相关支付凭证

## 配置项说明

### 1. 环境变量配置

在 `docker-compose.yml` 文件中配置以下环境变量：

```yaml
environment:
  # 微信支付配置
  WECHAT_PAY_APPID: your-wechat-pay-appid              # 微信小程序AppID
  WECHAT_PAY_MCH_ID: your-wechat-pay-mch-id            # 微信支付商户号
  WECHAT_PAY_API_KEY: your-wechat-pay-api-key          # 微信支付API密钥
  WECHAT_PAY_NOTIFY_URL: https://your-domain.com/api/payment/callback  # 支付回调地址
```

### 2. 配置参数详解

#### WECHAT_PAY_APPID（微信小程序AppID）
- **说明**：小程序的AppID，与微信商户号绑定
- **获取方式**：
  1. 登录[微信公众平台](https://mp.weixin.qq.com/)
  2. 进入"开发" -> "开发管理" -> "开发设置"
  3. 复制"AppID(小程序ID)"

#### WECHAT_PAY_MCH_ID（微信支付商户号）
- **说明**：微信支付分配的商户号
- **获取方式**：
  1. 登录[微信支付商户平台](https://pay.weixin.qq.com/)
  2. 进入"账户中心" -> "商户信息" -> "基本信息"
  3. 复制"微信支付商户号"

#### WECHAT_PAY_API_KEY（微信支付API密钥）
- **说明**：用于签名和验证的API密钥（32位字符串）
- **设置方式**：
  1. 登录[微信支付商户平台](https://pay.weixin.qq.com/)
  2. 进入"账户中心" -> "API安全" -> "API密钥"
  3. 点击"设置API密钥"
  4. 输入32位密钥（建议使用随机密码生成器）
  5. 保存密钥，**请妥善保管，泄露后需重新设置**

#### WECHAT_PAY_NOTIFY_URL（支付回调地址）
- **说明**：接收微信支付异步通知的URL
- **要求**：
  - 必须是HTTPS协议
  - 必须公网可访问
  - 格式：`https://your-domain.com/api/payment/callback`
- **配置方式**：
  - 生产环境：配置您的实际域名
  - 测试环境：可以使用内网穿透工具（如ngrok、花生壳等）

### 3. 微信支付商户平台配置

#### 3.1 配置支付回调URL

1. 登录[微信支付商户平台](https://pay.weixin.qq.com/)
2. 进入"产品中心" -> "开发配置" -> "支付配置"
3. 点击"修改"
4. 填写您的回调URL：`https://your-domain.com/api/payment/callback`
5. 保存配置

#### 3.2 配置小程序支付目录

1. 在"产品中心" -> "开发配置" -> "支付配置"
2. 在"小程序支付"栏目下
3. 添加支付目录：`https://your-domain.com/`
4. 保存配置

#### 3.3 配置H5支付域名（可选）

如果您需要H5网页支付，需要配置：
1. 在"产品中心" -> "开发配置" -> "H5支付"
2. 添加H5支付域名
3. 保存配置

### 4. 端口映射配置

确保您的服务器防火墙已开放以下端口：

```bash
# HTTP端口
firewall-cmd --zone=public --add-port=80/tcp --permanent

# HTTPS端口
firewall-cmd --zone=public --add-port=443/tcp --permanent

# 重启防火墙
firewall-cmd --reload
```

## 验证配置

### 1. 检查环境变量

启动服务后，检查环境变量是否正确加载：

```bash
# 查看容器环境变量
docker exec petlis-backend env | grep WECHAT_PAY
```

### 2. 测试支付接口

使用Postman或curl测试支付接口：

```bash
curl -X POST http://localhost:8080/api/payment/create \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{
    "orderId": 1,
    "amount": "0.01"
  }'
```

预期响应：
```json

  "code": 200,

    "nonceStr": "abc123",
```

### 3. 验证支付流程

1. 在小程序中创建订单
2. 选择检测项目，提交订单
3. 系统应调起微信支付
4. 完成支付后，订单状态应从"待支付(-3)"变为"待审核(0)"

## 常见问题

### Q1: 支付时提示"商户号未开通支付功能"

**解决方案**：
1. 登录微信支付商户平台
2. 确认已开通"小程序支付"产品
3. 检查商户号状态是否正常

### Q2: 支付回调无法接收

**解决方案**：
1. 检查回调URL是否可公网访问
2. 确认服务器防火墙已开放443端口
3. 查看后端日志，确认回调接口是否正常
4. 在微信支付商户平台检查回调URL配置

### Q3: 签名验证失败

**解决方案**：
1. 确认API密钥配置正确（32位字符串）
2. 检查商户号和AppID是否匹配
3. 确认请求参数格式正确

### Q4: 测试环境如何调试支付

**解决方案**：
1. 使用微信支付沙箱环境进行测试
2. 使用内网穿透工具（如ngrok）暴露本地服务
3. 在微信支付商户平台申请测试号

### Q5: 支付成功但订单状态未更新

**解决方案**：
1. 检查支付回调是否正常调用
2. 查看后端日志，确认回调处理逻辑
3. 确认数据库中订单状态字段是否正确更新
4. 检查`WeChatPayment`表中的支付记录

## 安全建议

1. **保护API密钥**：
   - 不要将API密钥提交到版本控制系统
   - 使用环境变量或密钥管理工具存储
   - 定期更换API密钥

2. **使用HTTPS**：
   - 生产环境必须使用HTTPS协议
   - 配置有效的SSL证书

3. **验证签名**：
   - 严格验证微信回调的签名
   - 防止恶意伪造回调

4. **日志记录**：
   - 记录所有支付相关的操作日志
   - 便于问题排查和审计
