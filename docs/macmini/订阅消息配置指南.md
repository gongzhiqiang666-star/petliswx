# 微信小程序订阅消息配置指南

## 📱 功能说明

订阅消息功能可以在订单状态发生变化时（如：待审核、检测中、已完成等），向用户发送微信服务通知，确保用户及时了解订单进展。

## ⚙️ 配置步骤

### 1. 在微信公众平台创建订阅消息模板

1. 登录 [微信公众平台](https://mp.weixin.qq.com/)
2. 进入小程序管理后台
3. 点击左侧菜单：**功能** → **订阅消息**
4. 点击**"选用模板"**按钮
5. 搜索关键词：`订单状态`、`审批通知` 或 `服务进度`
6. 选择合适的模板，点击**"确定"**

**推荐的模板字段**：
- 订单编号
- 订单状态
- 更新时间
- 备注说明

7. 记录模板ID（格式如：`ABC123-DEF456-GHI789`）

### 2. 配置小程序代码

#### 2.1 修改配置文件

编辑文件：`miniprogram/config/notification.js`

```javascript
module.exports = {
  // ⚠️ 将下面的值替换为您的真实模板ID
  TEMPLATE_ID: 'YOUR_TEMPLATE_ID_HERE',

  // 是否启用订阅消息
  ENABLED: true
}
```

**替换示例**：
```javascript
module.exports = {
  TEMPLATE_ID: 'ABC123-DEF456-GHI789',  // 替换为真实模板ID
  ENABLED: true
}
```

#### 2.2 验证代码已添加

确认以下文件已包含订阅消息相关代码：
- ✅ `miniprogram/config/notification.js` - 配置文件
- ✅ `miniprogram/pages/order-preview/order-preview.js` - 订单提交时请求订阅

### 3. 测试订阅消息功能

#### 3.1 开发工具测试

1. 在微信开发者工具中打开项目
2. 提交一个测试订单
3. 应该会弹出订阅消息授权弹窗

**注意**：开发者工具可能无法完全模拟真实环境，建议使用真机调试。

#### 3.2 真机调试测试

1. 在微信中打开体验版小程序
2. 提交一个测试订单
3. 应该会看到订阅消息授权弹窗：
   - **"保持以上选择，不再询问"** - 勾选后会长期订阅
   - **"允许"** - 同意接收本次消息
   - **"取消"** - 拒绝接收消息

## 📋 订阅消息授权结果说明

| 结果 | 说明 | 处理方式 |
|------|------|----------|
| `accept` | 用户同意订阅 | ✅ 正常提交订单，后续会收到通知 |
| `reject` | 用户拒绝订阅 | ⚠️ 正常提交订单，但不会收到通知 |
| `ban` | 用户已永久拒绝 | ⚠️ 提示用户到设置页面开启 |
| `errCode: 20004` | 用户关闭了订阅消息主开关 | ⚠️ 提示用户到设置页面开启 |

## 🔧 常见问题

### Q1: 为什么提交订单后没有弹出授权窗口？

**可能原因**：
1. ✅ 模板ID未配置（仍是 `YOUR_TEMPLATE_ID_HERE`）
2. ✅ `ENABLED` 设置为 `false`
3. ✅ 用户已经勾选了"总是保持以上选择，不再询问"

**解决方法**：
- 检查 `config/notification.js` 配置
- 确认模板ID已正确替换
- 在微信中：**我** → **设置** → **通用** → **发现页管理** → **小程序** → 订阅消息

### Q2: 开发环境和生产环境如何区分？

**建议配置**：

```javascript
// 获取小程序版本
const accountInfo = wx.getAccountInfoSync();
const envVersion = accountInfo.miniProgram.envVersion; // 'develop', 'trial', 'release'

module.exports = {
  // 开发版和体验版使用测试模板ID，正式版使用正式模板ID
  TEMPLATE_ID: envVersion === 'release'
    ? 'PRODUCTION_TEMPLATE_ID'
    : 'TEST_TEMPLATE_ID',

  // 只在生产环境启用
  ENABLED: envVersion === 'release'
}
```

### Q3: 订阅消息的有效期是多久？

- **一次性订阅**：7天有效期，过期后需重新授权
- **长期订阅**：用户勾选"总是保持以上选择，不再询问"后长期有效

**建议**：每次提交订单时都请求订阅，确保能接收通知。

### Q4: 如何修改订阅消息模板内容？

1. 进入微信公众平台
2. **功能** → **订阅消息**
3. 找到对应模板，点击**"详情"**
4. 点击**"修改"**按钮进行调整
5. 修改后需重新审核

## 🎯 使用效果

配置完成后，用户提交订单时会：

1. 弹出订阅消息授权弹窗
2. 用户同意后，订单状态变化时会收到微信服务通知
3. 通知内容包括：订单编号、状态、时间等信息

**示例通知**：

```
点击查看详情 >>
```
