# 资讯发布校验与幂等验证

## 已完成（2026-11-08）

检查发现发布接口仅检查直播链接前缀，日期、封面链接及摘要长度未充分校验；成功后响应丢失时，重复提交也没有请求去重。已补：

- 服务端校验分类/标题/正文、摘要1000字符、链接1000字符上限；封面和直播链接必须是有效HTTPS URL，禁止携带userinfo；直播须有真实日历日期和时间及链接。无效输入业务400，在写库和广播前拒绝。
- 发布支持可选`Idempotency-Key`，16–128位字母数字、下划线或连字符。PC每个弹窗生成一个稳定请求号，失败重试沿用，新弹窗生成新号。
- 复用既有`lin_audit_record`存请求号与内容SHA256；以操作人行锁及当前读串行核对，并在同事务创建文章、通知和审计。同一请求同内容返回原文章ID，不同内容409，缺失或异常原记录也409。
- 保持无请求号旧客户端兼容；旧客户端不因此自动获得请求去重保障，应逐步改为发送请求号。没有DDL、修改原PHP表结构、开启调度或外部发送。
