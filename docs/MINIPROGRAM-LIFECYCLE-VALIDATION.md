# 小程序版本、环境与本机诊断验证

2026-11-08，本机自动化专项；不代替微信真机验收。

## 环境配置

开发版未配置地址时使用127.0.0.1:8082/api，仍支持明确的本机/局域网开发地址。体验版和正式版必须显式提供HTTPS baseURL；缺失时拒绝回退本机，两个版本均禁止mock支付。未知/读取失败的运行版本不降级为develop。拒绝非HTTP协议、含用户凭据、查询、片段、空白的接口地址。地址只规范化尾斜杠及/api，不提供生产凭据或自动配置真实交易。

这不是微信合法域名配置完成的证明。试用/发布前仍需提供对应HTTPS域名并在微信后台完成域名配置；本机开发豁免只适用于已授权开发工具项目。

## 更新体验

现有更新机制仅下载完成后询问，提醒先保存送检草稿；用户确认才applyUpdate。测试确认重复就绪事件不重复弹窗、取消不重启、后续可再次确认、弹窗失败不重启、不支持更新API时不阻断启动。没有将表单自动保存为草稿，也未在真实微信安装版本间验证更新。

## 错误与隐私

应用onError/onUnhandledRejection仅在本机保留最近20条：时间、错误类别、已知页面、最多5条代码文件名和行列，不保存原消息、原路径、查询、账号/诊断内容，不自动上传。设置页复制或清除。新增缓存读取白名单校验，污染记录的任意字段、未知页面、完整URL、过长代码位置及非法类型/时间被丢弃；存储异常不影响业务。

这不是服务端远程错误上报。正式隐私说明、设备覆盖和真实崩溃收集仍待验收。

匿名业务事件另有analyticsEnabled配置；测试验证关闭后清空待发队列、不再新增/发送。未关闭前已被服务器接收的计数不会因客户端关闭而删除；配置不是个人用户设置页中的通知开关。
