## 修复的操作体验

- 确认页返回再进入原来自动按“不使用优惠券”核价，静默清掉之前的抵扣。现在恢复仍可用的券并重新核价。
- 换券核价失败原来保留上一张券ID，重试可能与当前选择不一致。现在先保存本次选择，失败后按本次选择重试；选择失效旧券会令旧在途核价失效，防止成功旧响应重新启用提交。
- 上次券已不可用时保留明确的失效选项，清掉有效报价并禁用提交，用户主动选择“不使用”或其他券后再核价。固定操作区同步显示阻止原因，不让用户只看到灰按钮。
- 分类请求按最后一次响应更新，加载时清旧列表并提示，旧分类响应不能覆盖新分类或提前结束加载。
- 原生测量发现6个分类按钮横排越界：390宽视口中每个按钮宽184，第三项起在屏外。改为两行三列；原生边界实测6项均在视口内。
- 有效期保留到具体分钟，避免只显示日期掩盖当天提前到期；详情长值允许换行。
