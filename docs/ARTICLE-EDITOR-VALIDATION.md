# 资讯草稿、编辑与下架管理

## 实现范围（2026-11-08）

复用既有`lin_article`与`lin_audit_record`，没有DDL。新增仅审核员/ADMIN可用的`/admin/articles`列表、详情、新建草稿、编辑和状态操作；PC运营资讯切换为专用管理列表，支持全部/草稿/已发布/已下架筛选。保留直接发布入口及其稳定请求号。

- 草稿要求分类、标题和类型，可暂留空正文；直播草稿可暂不填时间/链接。发布时执行完整校验。
- 修改和状态操作要求原因、预期版本与稳定请求号。版本取对应ARTICLE最新审计ID，原表不增加版本列；读取编辑详情时锁定行，防止内容和版本来自不同并发状态。
- 同一请求重复操作可重放，不同内容或跨文章复用请求号冲突。操作人锁、文章锁及READ_COMMITTED下的独立版本查询保证并发编辑不会静默覆盖。
- 草稿可发布或归档，已发布可下架；下架须先恢复草稿再发布。保留原ID、内容、发布时间和操作前后快照；编辑不重发通知，重复发布沿用原article业务键去重。
- 小程序公开列表/详情仅返回已发布内容。详情重新加载失败会清掉旧内容和倒计时，避免下架后错误提示下仍显示旧正文。
