# M22 按收样时间期间生成财务草稿

## PHP 源码 → Java → PC

只读依据：finance/Hospmonthpeport.php::send 在未给hospid的分支调用Backend::buildparams，ReceiveSampleDt使用RANGE/BETWEEN TIME精确比较；dt1/dt2另取日期用于标题和占位符。contents中的结算月份取dt1月份，不按跨月范围重新汇总或改变合计方法。

Java LegacyMonthlyReportService新增rangeDraft，控制器 GET admin/legacy/monthly-reports/{hospital}/range-draft，from/to使用ISO本地时间精确到秒，双端包含且不扩大到全天。月报和期间草稿复用同一明细查询、20000条保护、未结非豁免合计、模板及付款链接替换。期间month保留空串，标题为起始日期-结束日期加医院名及原账单后缀，PDF标题同原规则。此入口不写通知记录。

PC月报页新增医院编号与收样起止时间生成期间草稿，支持秒输入，更换模板保持同一期间，复用已有两份正文编辑与预览；原月份入口保持。

## 剩余与边界

本轮实现有明确起止时间的医院期间，不宣称通用PHP组合筛选、单侧开区间、缺少日期时标题/查询不一致路径已全部复刻。财务PDF正式分页仍待M17既有决定；持久化附件、收件/投递、成功通知回写、历史与整模块两轮复核未完成。原PHP只读，无DDL、外发或作业启用。
