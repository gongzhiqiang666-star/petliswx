# M11 本院旧草稿资料接续

## 源码依据与本次落点

只读参考 `application/index/controller/User.php::SendPro1`（333行起）、`application/index/model/LbListdiagnosisproject.php`、`application/index/view/user/send_pro1.html`，以及原品种/采样类型选择入口。原创建和修改不是同一套回调：创建会固定数据组、初始状态、生日、品种副本和默认值；修改现有记录只更新提交字段，没有相应 beforeUpdate 业务回调。

本轮仅实现**已有本院原草稿**的读取与资料更新，不执行 admin 主单回调，不运行新建默认值，不将旧单复制成新单。落点 LegacyHospitalDraftService，以及 `/orders/hospital-history/drafts` 列表、`/drafts/{id}` GET/PUT、`/draft-choices/{kind}`。

编辑字段白名单按原第一步表单：畜主、动物、品种ID、年龄、性别ID、采样日期/类型/部位、医师及备注。API保留备注原HTML；原生页当前编辑前九项，**备注只做文字预览，不改原文**，富文本维护仍是未完成项，不能据原文保存称编辑能力已齐。

关键兼容规则：

- 范围按医院，不按录入医生，原 CreateSampleId=0 的历史草稿也可接续；原新系统个人JSON草稿保持独立。
- 已有草稿改年龄不重算 Birthday，改品种ID不重算 AnimalType/AnimalType_en，保存不更改创建时间、付款/金额/其他状态或正文。原PHP也只在插入时写这些副本，本轮不擅自修正该旧行为。
- 性别选项按原 IsActive=0，与新通用字典的1相反；品种及采样类型沿用原未加启停过滤的范围。未匹配或不在当前搜索页的原选项会保留，不自动清空。
- 选择器实现改为普通原生picker、搜索和更多，不模仿旧插件。只发送修改字段；未改日期和备注不被界面初始化重写。

## 参数、权限与事务

复用现有 `legacy-hospital-history` 配置：enabled及draftEnabled严格布尔true才可读取；再同时满足writeEnabled及draftWriteEnabled才可保存。默认关闭。角色和明确医院范围由Java会话与AccessService校验；已进入新扩展、运单或报告工作流的记录不走旧草稿入口。

主单全行快照令牌、请求内容和请求号防止覆盖他人更新及重复写入。更新锁参数/操作人/主单，同事务写原字段和现有Java审计记录；审计失败整次回滚。不增表、不改原SQL结构或触发器，不调用PDF/扣款/发邮件回调。

原生“草稿”页新增本院历史草稿区域：分页、打开、选择/搜索、资料保存、重新读取；与个人草稿使用独立加载和错误状态。响应丢失重试复用请求号；保存成功但重读失败明确显示“已保存，需重新打开核对”，不继续展示可误写的另一份旧表单。
