# M07基础字典：首批只读能力迁移记录

日期：2026-11-08。范围为原物种、性别字典的普通列表读取与展示，不是完整M07，也不是两轮完整复核已通过。

## 原PHP与新实现

原控制器basedata/LbInfoanimal、data/LbDictsex继承通用列表；原JS列项与语言包提供名称/英文名、状态、创建/更新时间和Id，状态1“正常”、0“禁用”。原新增表单默认IsActive=0。新LegacyDictionaryService保留两表原字段与标签，不复制主数据表；新PC“基础数据管理”提供物种/性别切换、中英文独立查询、状态、创建/更新时间范围、排序和分页。时间以Unix秒读取、上海时区显示到秒，空/0显示“无”。界面使用我们的卡片/表单/表格风格。

新增GET /admin/legacy/capabilities、/admin/legacy/dictionaries、/admin/legacy/dictionaries/{species|sex}。仅ADMIN，运营参数legacy-dictionaries必须为GLOBAL/0、ACTIVE且enabled为JSON布尔true；缺失、false或字符串“true”不开放。模块默认关闭，前端按能力隐藏入口，后端仍拒绝直接访问；既有页面不受能力接口失败影响。没有新增字典写接口、DDL或PHP代码。
