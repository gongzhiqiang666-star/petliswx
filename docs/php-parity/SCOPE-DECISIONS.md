## 本轮发现但未擅改

当前第三次寄件合成单的旧ReceiveSampleDt仍是默认日期，而新工作流有实际实验室签收节点。进一步核对原语言包`application/admin/lang/zh-cn/project/lb_listdiagnosisproject.php:25`及编辑模板`application/admin/view/project/lb_listdiagnosisproject/edit.html:255`，明确该列为“收到样本日期”；导出中“采样日期”是错误注释，不能据此改字段语义。现有ShipmentWorkflowService签收只更新运单并建任务，没有回写该旧列；旧月报又按该列筛选，故登记为收样日期双端同步缺口。

当前已批准兼容范围内现已修复应用事务同步：实际实验室签收才补缺失收样日期；物流妥投不补；有效旧日期保留；重复签收不覆盖或重复建任务，建任务失败整段回滚；不批量追补历史，不改表结构。5项实库及后端487项全过，详见[验证报告](../LAB-RECEIPT-DATE-SYNC-VALIDATION.md)。采样日期缺失不因报告发布伪造采样时间。此修复不代表批准PHP全量迁移，也未宣称月报视觉或新一轮PHP浏览器验收。
