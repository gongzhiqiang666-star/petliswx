# 医院资金池首批服务与PC入口验证

## 已迁能力

- Java直接使用旧lin_lb_infohospital.amount与lin_infohospital_money，无PHP桥接、DDL或PHP修改。
- 保留加减款、零额拒绝、余额不足提示、原管理员ID、备注、Unix秒时间和只增不可编辑/删除的资金流水。
- 保留医院资金池与lin_user.money个人钱包独立。当前服务不操作个人余额/流水。
- 原管理员身份必须通过`legacy-hospital-funds`配置`adminMappings`可信映射（新用户ID字符串→旧lin_admin.id整数）；旧管理员须存在且normal。不把新用户ID直接写为旧管理员ID。当前本机配置映射为空，写入关闭。
- `enabled`、`writeEnabled`严格JSON布尔开关；管理员校验；服务端不接受调用者伪造admin_id。
- 同事务锁定操作者与医院记录，余额/流水/审计共同提交；请求号按操作者防重，内容不同409，规范金额与排序后JSON保证跨重启一致。
- PC“用户与医院→医院档案→医院资金”：余额、医院名、原流水列、翻页、金额（负数为扣）及备注；只读开关不展示写入表单，关闭模块隐藏入口。
